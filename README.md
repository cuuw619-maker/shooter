# SHOOTER — 3D P2P FPS

Браузерный сетевой шутер от первого лица для **ПК и телефона**. Проект запускается прямо в браузере и не требует установки отдельного клиента.

## Сайт и репозиторий

- **Играть:** https://cuuw619-maker.github.io/shooter/
- **GitHub:** https://github.com/cuuw619-maker/shooter
- **Исходный код:** https://github.com/cuuw619-maker/shooter/tree/main

> Если GitHub Pages ещё не включён в настройках репозитория, ссылка на игру станет доступна после включения Pages для ветки `main`.

## Что уже есть

### 3D FPS
- Вид от первого лица.
- Полноэкранный режим.
- 3D-сцена на Three.js.
- Освещение, туман, пол и игровая арена.
- Генерация препятствий на карте.
- Прицел и HUD.
- HP и счёт игроков.
- Прыжок и базовое перемещение.

### Онлайн P2P
Игра использует **PeerJS + WebRTC**.

1. Первый игрок нажимает «СОЗДАТЬ КОМНАТУ».
2. Игра создаёт пятизначный код.
3. Код передаётся второму игроку.
4. Второй игрок вводит код и нажимает «ВОЙТИ».
5. После установления WebRTC-соединения игроки обмениваются игровым состоянием напрямую.

PeerJS используется для сигнализации и установления соединения. После подключения игровые данные передаются через P2P DataChannel.

## Управление

### ПК

| Действие | Управление |
|---|---|
| Движение | WASD |
| Обзор | Мышь |
| Стрельба | ЛКМ |
| Прыжок | Space |
| Полный экран | Кнопка ⛶ в HUD |

### Телефон

Интерфейс автоматически переключается на touch-управление:

- левый виртуальный стик — движение;
- правый виртуальный стик — обзор;
- **FIRE** — стрельба;
- **JUMP** — прыжок;
- **⛶** — полноэкранный режим.

Кнопки рассчитаны на нажатие пальцем: увеличены зоны касания, отключены случайные выделения и добавлена адаптация под safe-area современных телефонов.

## Запуск локально

Для сетевых возможностей рекомендуется HTTPS или localhost.

```bash
python -m http.server 8000
```

После этого открыть:

```text
http://localhost:8000
```

Для игры с телефона через интернет лучше использовать GitHub Pages или другой HTTPS-хостинг.

## Важные ограничения текущего прототипа

- попадание пока не использует полноценный raycast;
- столкновения игрока с препятствиями пока не реализованы;
- карта генерируется случайно на каждом клиенте и ещё не синхронизируется seed/layout;
- комната рассчитана на базовый сценарий из двух игроков;
- авторитетная серверная проверка попаданий отсутствует.

Следующий этап — полноценная система оружия, raycast, коллизии, перезарядка, синхронизация карты и более надёжная сетевая модель.
