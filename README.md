# Shooter

Базовый 3D FPS для телефона и ПК.

- Three.js — рендеринг FPS.
- PeerJS/WebRTC — P2P DataChannel.
- Хост автоматически получает пятизначный код комнаты.
- ПК: WASD, мышь, ЛКМ, Space.
- Телефон: левый стик — движение, правый — обзор, FIRE/JUMP.
- Без отдельного игрового сервера: PeerJS используется как signaling-сервис, игровой трафик после соединения идет P2P.

Открывается как обычный `index.html` через HTTPS/localhost.
